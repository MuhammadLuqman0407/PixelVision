# PixelVision

PixelVision is a lightweight browser-based image enhancer with a polished glassmorphism UI.

## Features

- Upload images from local files
- Apply brightness, contrast, saturation, and blur adjustments
- Download edited images
- Clean modern glassmorphism interface
- Responsive layout for desktop and tablet

## Files

- `index.html` — main UI structure
- `style.css` — glassmorphism and layout styles
- `script.js` — image loading and filter behavior

## Usage

1. Open `index.html` in a browser.
2. Click **Choose Image** and select a photo.
3. Adjust filters on the right panel.
4. Click **Download** to save the edited image.
5. Click **Reset** to restore default settings.

## Notes

- Works best in modern browsers with canvas support.
